# Archived result provenance

The archived CSVs were copied byte-for-byte from the thesis working directory's `results/` folder. They contain experiment-level scalar metrics, not candidate rows, raw predictions, demographic samples or embeddings. They were not regenerated by publication preparation.

`results.csv` contains one row for each fusion × condition × seed. All eight shared metrics agree within 1e-12 with the original separate early/late CSVs and the width-50 subset of the original mid CSV: 600 scalar comparisons. Its extra columns hold late-fusion modality-specific MAEs or mid text width, with blanks elsewhere.

**Important archival mismatch:** the separate original `results_mid.csv` contains widths 50 and 38, whereas the current original mid notebook sweeps 50, 45, 35 and 25. The canonical main CSV uses width 50 and agrees with both the width-50 separate result subset and the width-50 sensitivity results. The width-38 file is not redistributed, and no claim is made that the current notebook generated every historical CSV in one execution. The exported main mid notebook is explicitly restricted to width 50.

The sensitivity file is 4 widths × 5 conditions × 5 seeds. The internal probe file is 25 groups × 5 seeds: early and mid each have an `all` branch; late has three modality-specific branches. These supplemental runs must not be counted as main experiment cells or interpreted as candidate-level accuracy samples.

`assets/summary.csv` is newly derived by `scripts/make_overview.py`: 15 groups × 8 metrics = 120 rows. Every SD is the sample standard deviation over seeds 32–36 (n=5). No seed SD is inferred from missing runs and no per-person uncertainty is claimed. The PNG is generated from those same verified means/SDs.

## Publication transformations

Seven notebooks are exported with outputs cleared, execution counts null, empty global/cell metadata, and new neutral cell IDs. Code is otherwise preserved except:

- Main mid-fusion defaults to text width 50 instead of the historical width sweep.
- Label-baseline helper import is made relative to the documented `notebooks/prep/` working directory; top-10 candidate examples are removed.
- Unfinished and unsupported informal baseline notebook commentary is replaced with neutral task descriptions.
- Upstream-identical KL code is excluded and replaced separately, as described in `RIGHTS.md`.

The static chart script, compatibility KL implementation, tests, docs and dependency declarations were added during publication preparation. They must not be represented as code originally written during the thesis.
